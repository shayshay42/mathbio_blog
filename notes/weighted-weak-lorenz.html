Weak forms, weighted windows, and Lorenz

Can a weak formulation make learned dynamics more robust to noisy observations? And does giving less weight to the ends of a trajectory help? This Lorenz63 benchmark tests both questions. The weak formulation helps under noise; the extra endpoint weighting gives no consistent gain.

Methods

The reference system is Lorenz63, with σ = 10, ρ = 28, and β = 8/3:

dx/dt = 10(y − x)dy/dt = x(28 − z) − ydz/dt = xy − (8/3)z

After a 100-time-unit spin-up, states are sampled every 0.01 time units. Each of five final splits contains 64 training trajectories of length 20, 32 validation initial conditions, and 128 held-out test initial conditions. Hyperparameters are selected on a separate development split and then frozen. Gaussian noise is added only to training observations, at 0%, 0.1%, 1%, or 5% of each coordinate’s clean training standard deviation.

Strong SINDy estimates derivatives from the observed states, then fits a polynomial vector field. Weak SINDy instead fits integrated equations. For a compact test function φ and a candidate library Θ, integration by parts gives

−∫ x(t)φ′(t) dt = ∫ Θ(x(t))ξφ(t) dt.

The derivative acts on the known test function rather than the noisy observations. The implementation uses 81-sample windows, a 20-sample stride, four polynomial–Legendre test functions, and trapezoidal quadrature. The weak variants share a quadratic library and the same fitting settings.

Endpoint-weighted weak SINDy keeps those local integrals unchanged. It weights the resulting regression rows by their window’s position along the trajectory, using the smooth taper

w(s) = exp(4 − 1/[s(1 − s)]),   0 < s < 1.

The endpoint weights are zero; weights are normalized to unit mean. Both sides of each regression equation are multiplied by √w. This isolates the effect of endpoint weighting. Uniform weights recover the unweighted weak fit. Both weak variants use feature-scaled regression with ridge 10−8; the frozen threshold is zero, so these runs do not prune coefficients.

The figure also includes strong-loss, weak-form, and soft-DTW neural ODEs. Dashed AD Lorenz curves fit parameters within the known equation form; dotted PINN and numerical-oracle curves use the exact physics. These information tracks help interpret the curves, but their unequal prior knowledge prevents a single fair ranking across all methods.

Learned autonomous forecasts use float64 RK4 with step 0.001 against a DOP853 reference, independently checked with Radau. The error is the squared state error divided by the sum of training-coordinate variances. Valid prediction time, or VPT, ends at the first error above 0.4. Time is reported as λmaxt, with λmax ≈ 0.9134. Forecasts that do not cross the threshold are right-censored at the valid evaluation horizon.

Results

At 5% noise, weak SINDy retains about 1.73 more Lyapunov times than strong SINDy. Their 95% bootstrap intervals are 4.623–4.915 and 2.824–3.241 LT, respectively. Weighted weak SINDy reaches 4.656 LT, with an interval of 4.383–5.060 LT. It is nearly tied with weak SINDy on clean data, slightly ahead at 0.1% noise, and below it at 1% and 5%. These runs do not establish a consistent benefit from the extra weighting.

Intervals come from the existing paired hierarchical bootstrap: 10,000 resamples over splits, model runs, and test trajectories. Three model seeds are recorded per split, but the SINDy fits are deterministic; those repeated seed runs are not independent fits.

The near-horizontal oracle curve is a numerical reference within the plotted horizon. It does not show that learned models have unlimited forecast accuracy.

The main limitation is structural: the SINDy libraries contain the true Lorenz terms. The result supports weak-form noise robustness for this system and protocol. It does not establish an advantage on arbitrary dynamics, and it leaves the proposed endpoint-weighting benefit unsupported here.
